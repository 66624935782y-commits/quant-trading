# 行情分析与数据保存

第 2 阶段加入了公开 K 线、图表和本地行情记录。所有操作保持 PAPER 模式，无需币安账户或 API 密钥，也不调用真实下单、提现、转账或杠杆接口。

## 先看离线演示

打开网页的“行情分析”页签，默认显示人工生成的演示 K 线。页面明确标注**离线演示**，来源记录为 `synthetic_demo`。

演示数据帮助检查图表、数据处理、保存和重新加载流程，不是币安历史行情。切换市场、交易对和周期后，点击左侧 **加载离线演示并保存**，按所选参数生成并保存一份演示数据；它也不会变成真实行情。初次打开的默认演示尚未写入磁盘，点击该按钮才能保存。

K 线包含开盘价、最高价、最低价、收盘价和成交量。每根 K 线对应选择的周期：`1m` 是 1 分钟，`1h` 是 1 小时，`1d` 是 1 天。图表与页面获取时间使用北京时间；CSV 和原始记录使用 UTC，北京时间为 UTC 加 8 小时。

## 手动获取公共行情

1. 在“行情分析”选择**现货**或 **USDT 本位永续合约**。
2. 选择 `BTC/USDT`、`ETH/USDT` 或 `SOL/USDT`。
3. 选择 `1m`、`5m`、`15m`、`1h`、`4h` 或 `1d`，再选择 200、500 或 1,000 条。
4. 点击 **拉取公共行情并保存**，等待结果；成功时自动保存。查看来源、请求参数、获取时间及告警。

此阶段每次请求近期的一段 K 线，不支持自选多年起止日期或自动连续下载。它不是逐笔报价页面，也不会后台持续刷新。公共行情来源标记为 `binance_public`，现货与合约数据分开存储。

**选择 USDT 本位合约只会切换行情来源。** 页面不提供杠杆、做空、合约订单或真实资金操作，模拟账户仍是固定 BTC 价格的虚拟现货练习。

## 为什么显示条数可能少于请求条数

交易所返回的数据可能含尚未收盘的最后一根 K 线。平台保留原始数组，但分析和 CSV 只保留获取时刻已经收盘的数据；未来 K 线也会被过滤。

处理流程将时间转换为 UTC 并排序，同一时间的相同数据去重；若同一时间有互相冲突的数据，直接报错。时间缺口或不符合周期的间隔会给出告警，不用插值补出价格。无效数值或不符合开高低收关系的数据会被拒绝。

页面的“最新已收盘价”是最后一根**已收盘** K 线的收盘价，不是当前逐笔成交价。区间涨跌幅按第一根开盘价与最后一根收盘价计算，是这段行情的价格变化，**不代表账户收益或回测收益**。

## 保存和重新加载

1. 确认左侧的市场、交易对、周期符合预期，然后点击 **拉取公共行情并保存** 或 **加载离线演示并保存**。
2. 成功后打开“数据记录”，选择所需记录并点击 **校验并重新加载**。
3. 返回“行情分析”，核对来源、条数、时间范围和图表；打开“查看 K 线表格与下载”，点击 **下载已收盘 K 线（CSV，UTC）**。

每次保存创建独立记录，不覆盖之前的数据。项目文件夹内的位置如下：

```text
data/raw/spot/BTCUSDT/1h/某次运行标识/
    raw.json
    candles.csv
    manifest.json
```

合约对应的市场目录是 `usdt_futures`。`raw.json` 保留原始 K 线数组，`candles.csv` 是已校验、去重且排除未收盘数据的分析结果，`manifest.json` 记录来源、请求参数、UTC 获取时间、告警、条数、格式版本与文件校验值。演示数据保存后仍标记为演示。

重新加载会检查文件校验值，并将原始数据重新处理后与 CSV 对照。文件缺失、损坏或内容被修改时，会报完整性错误；保留原文件和错误信息，不要修改校验值来强行加载。可以重新获取行情并保存为新的记录。

下载 CSV 适合在 Excel 等软件查看；需要完整保留原始数据、来源与校验信息时，应备份整个 `data` 文件夹。**安装 ZIP 和 GitHub 源码不包含你本机的行情文件。** 升级前另行备份，不要用新的项目目录覆盖旧数据。

## 公共行情请求失败怎么办

首次安装依赖使用网络，公共行情获取也使用网络。离线演示和加载本地已保存记录不需要连接币安。

现货行情访问 `data-api.binance.vision`，USDT 本位合约访问 `fapi.binance.com`。请求可能因为超时、交易所服务状态、网络策略或地区限制失败。页面会说明错误，**不会静默替换成演示数据**，也不会要求输入密钥。

失败时图表保留上一次数据，当前来源和参数仍显示在图表说明中，避免把旧数据误认为本次成功获取。查看错误内容，确认当前网络和服务是否可用；若确有服务或地区访问限制，保留错误信息并使用明确标记的演示数据或已保存记录继续练习。本项目不提供绕过地区限制的操作，也不通过关闭 TLS 验证解决连接问题。

当前云环境的真实现货与合约请求均被代理以 `403` 拒绝，尚未验证真实行情连通性。你的 Windows 网络可能不同，应以页面实际结果为准；自动化测试使用固定样本，测试通过不代表一定能连接交易所。

## 本阶段验收与下一阶段

- 离线演示的来源清楚，K 线和成交量正常显示。
- 公共请求成功时，来源为币安公共行情；失败时，页面保留明确错误。
- 保存记录后能够重新加载，来源、条数与图表一致；被修改的文件不能通过完整性检查。
- 行情切换与加载不会改变虚拟账户，模拟买卖不调用真实订单接口。

本阶段尚未计算策略收益、最大回撤或资金曲线，也不会自动运行策略。下一阶段将使用保存的历史数据建立现货回测，按下一根 K 线成交，加入手续费、滑点、资金与仓位约束，并验证未来数据不会影响先前信号。
