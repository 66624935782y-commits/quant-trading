# 币安账户只读诊断工具

无需重装交易助手，也不用把 .env 复制或发送给任何人。

1. 将本压缩包下载到自己的电脑，右键“全部解压”。
2. 进入能看到 check_api.bat 的文件夹，双击 check_api.bat。
3. 在弹出的文件夹选择窗口中，选择你**原来的交易助手文件夹**（里面有 start.bat、.env 和 .venv，例如 E:\虚拟量化），点击确定。不要选择刚下载的诊断文件夹。
4. 等待黑色窗口输出结果。只发送这个结果或原程序 runtime/api_diagnosis.txt，不要发送 .env、API 管理页或原始账户日志。

只会读取 .env 并调用 CCXT 的公开时间、USDT 合约余额、持仓和一条收益流水 GET 接口，不下单、撤单、平仓或设置杠杆。不修改 .env、数据库或交易设置。输出的摘要只有阶段、状态、固定中文说明、数字错误码及币安可选报告的请求 IP；不包含 Key、Secret、签名、余额、仓位或收益数值。网络超时可能需要等待数十秒，失败后停止后续步骤。

如果密钥已经出现在聊天或截图中，请先在币安撤销它并重新创建，只在本机 .env 保存新密钥。LIVE_TRADING 保持 false。-2015 同时可能表示密钥、IP 白名单或权限不符，不能只凭这个码确定原因。浏览器的出口 IP 不一定等于 Python 的出口；不要取消 API IP 限制来排查。

工具使用你原来已安装的虚拟环境，无需另外安装依赖。Windows 文件夹选择步骤未在本机实测；诊断 Python 逻辑已通过隔离测试，不代表真实账户连通性已验证。
